📚 Sistema de Biblioteca
📌 Sobre o projeto

O Sistema de Biblioteca é um sistema desenvolvido para auxiliar no gerenciamento de uma biblioteca, facilitando o controle de livros, usuários, empréstimos e devoluções.

🎯 Objetivo

O objetivo do projeto é desenvolver um sistema que permita organizar o acervo da biblioteca e facilitar o gerenciamento dos empréstimos e devoluções de livros.

❗ Problema

O controle manual de livros e empréstimos pode causar dificuldades na organização do acervo, perda de informações, atrasos nas devoluções e dificuldade para localizar livros.

O sistema busca solucionar esses problemas por meio da informatização das principais atividades da biblioteca.
